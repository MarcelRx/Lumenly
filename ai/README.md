# AI Modules

Python packages for LLM orchestration, semantic memory, multi-agent flows, and voice.

| Module | Path | Purpose |
|--------|------|---------|
| Memory Engine | `memory_engine/` | Vector store wrapper & Qdrant utils |
| Knowledge Brain | `knowledge_brain/` | LLM prompting, Groq/Gemini clients, RAG |
| Agent System | `agent_system/` | Multi-agent orchestration layer |
| Voice | `voice/` | ElevenLabs integration |

See [`docs/ai_system_design.md`](../docs/ai_system_design.md) and [`docs/project_structure.md`](../docs/project_structure.md) §5–8.
